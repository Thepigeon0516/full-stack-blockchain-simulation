# Blockchain Simulation

* Developed a full-stack web application that simulates a cryptocurrency ledger with a RESTful backend and persistent data storage.
* Engineered a backend using Node.js and Express to handle API routing for processing transactions and the blockchain ledger.
* Implemented an algorithm that used SHA-256 hashing to validate and mine new blocks.
* Integrated a SQLite3 database to create the genesis block and prevent hash collisions.
* Built a responsive dashboard using HTML and Bootstrap 5 that used the Fetch API for client-to-server communication.
